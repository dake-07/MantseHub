## ✨ Features

- **Premium UI/UX:** A stunning, minimalist design featuring glassmorphism, dynamic scroll effects, and refined typography.
- **Smooth Animations:** Powered by Framer Motion, featuring buttery-smooth micro-animations, hover states, and page transitions.
- **Fully Responsive:** Flawless layout adaptation across all devices—from mobile phones to ultra-wide desktop monitors.
- **Seamless Navigation:** Client-side routing with React Router for instant, zero-refresh page loads.
- **Global Cart State:** Efficient, robust cart management utilizing React Context API, complete with an interactive slide-out Cart Drawer.
- **Dynamic Product Filtering:** Easily sort and discover products through the intuitive Category and Brand showcase systems.
- **Store Locator:** Integrated, lazy-loaded Google Maps for seamless physical store discovery without impacting initial page load performance.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Routing:** React Router v7
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dake-07/MantseHub.git
   cd MantseHub
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables (if required):
   Create a `.env.local` file in the root directory and add any necessary keys, such as your Gemini API key (if leveraging AI features).
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
   *Note: The application is configured to run on port 3000 (`http://localhost:3000`).*

## 📦 Deployment

To create a production-ready build:

```bash
npm run build
```

This will generate an optimized build in the `dist` folder. If you are deploying to GitHub Pages, ensure your deployment workflow points to this directory.
